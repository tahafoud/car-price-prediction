# مشروع التنبؤ بأسعار السيارات باستخدام تعلم الآلة

## نبذة عن المشروع

يهدف هذا المشروع إلى بناء تطبيق تفاعلي يساعد على **تقدير سعر السيارة** اعتمادًا على مجموعة من الخصائص، مثل الشركة المصنّعة، وسنة الصنع، والمسافة المقطوعة، ونوع الوقود، ونوع ناقل الحركة، وسعة المحرك، والقوة، وعدد المقاعد.

يستخدم المشروع لغة **Python** وأدوات تحليل البيانات وتعلّم الآلة، مع واجهة تفاعلية مبنية باستخدام **Streamlit** تتيح للمستخدم إدخال مواصفات السيارة وعرض السعر المتوقع من النموذج المدرّب.

> **تنبيه:** السعر الناتج هو تقدير يتأثر بجودة البيانات وطريقة تدريب النموذج، ولا يُعد تقييمًا رسميًا أو ضمانًا لسعر البيع الفعلي.

## أهداف المشروع

- استكشاف بيانات السيارات وتجهيزها للاستخدام في تعلّم الآلة.
- استخدام نموذج مدرّب للتنبؤ بسعر السيارة.
- تقديم واجهة سهلة لإدخال مواصفات السيارة وتجربة التنبؤ.
- تنظيم ملفات البيانات والكود والنموذج ضمن مستودع واحد يسهل مراجعته وتطويره.

## التقنيات المستخدمة

- **Python** — لغة البرمجة الأساسية.
- **Pandas** — قراءة البيانات ومعالجتها.
- **NumPy** — العمليات العددية.
- **Scikit-learn** — أدوات تعلّم الآلة، بحسب خطوات التدريب الموجودة في الدفتر.
- **Streamlit** — بناء واجهة التطبيق التفاعلية.
- **Pickle** — تحميل النموذج المحفوظ.

## هيكل المشروع

```text
car/
├── code/
│   ├── app.py                 # تطبيق Streamlit
│   └── Car_Price_Model.ipynb  # دفتر تحليل البيانات وتدريب النموذج
├── data/
│   └── Cardetails.csv         # بيانات السيارات
└── outputs/
    └── model.pkl              # النموذج المدرّب
```

## مدخلات التنبؤ

تتيح الواجهة إدخال مجموعة من خصائص السيارة، منها:

- الشركة المصنّعة.
- سنة الصنع.
- المسافة المقطوعة بالكيلومترات.
- نوع الوقود.
- نوع البائع.
- نوع ناقل الحركة.
- عدد المالكين السابقين.
- معدل استهلاك الوقود أو المسافة لكل وحدة وقود كما هو ممثل في البيانات.
- سعة المحرك.
- القدرة القصوى.
- عدد المقاعد.

تُحوَّل بعض القيم الفئوية إلى قيم رقمية داخل التطبيق قبل إرسالها إلى النموذج. يجب أن تتطابق هذه التحويلات وترتيب الأعمدة مع المعالجة المستخدمة أثناء التدريب.

## متطلبات التشغيل

تأكد من تثبيت Python، ثم ثبّت المكتبات اللازمة في بيئة العمل:

```bash
pip install pandas numpy scikit-learn streamlit
```

إذا احتوى دفتر التدريب على مكتبات إضافية، فيجب تثبيتها أيضًا وفقًا لما يتطلبه الدفتر.

## تشغيل التطبيق

من المجلد الرئيسي للمشروع، شغّل التطبيق باستخدام:

```bash
streamlit run code/app.py
```

### مسارات الملفات

يحدد التطبيق مساري النموذج والبيانات انطلاقًا من موقع `app.py`، لذلك يمكن تشغيله من المجلد الرئيسي للمشروع أو من مجلد عمل آخر:

```bash
streamlit run code/app.py
```

كذلك، ينبغي التحقق من أن تحويل القيم الفئوية في التطبيق مطابق تمامًا للتحويلات المستخدمة عند تدريب النموذج. لا يُنصح بتغيير ترميز الفئات بصورة مستقلة عن التدريب، لأن ذلك قد يؤدي إلى تنبؤات غير صحيحة.

## خطوات العمل المقترحة

1. مراجعة البيانات الموجودة في `data/Cardetails.csv`.
2. فتح دفتر `code/Car_Price_Model.ipynb` لفهم التنظيف والمعالجة والتدريب.
3. التأكد من أن النموذج المحفوظ في `outputs/model.pkl` هو النموذج الناتج عن خطوات التدريب نفسها.
4. تصحيح مسارات النموذج والبيانات في التطبيق.
5. تشغيل التطبيق وتجربة مدخلات مختلفة والتحقق من أن التنبؤات تعمل دون أخطاء.
